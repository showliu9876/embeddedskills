# EIDE unify_builder Reference

## unify_builder CLI

`unify_builder` is the unified build backend of the EIDE extension, located in the VS Code extensions directory:

```
<vscode-extensions>/cl.eide-<version>/res/tools/linux/x86_64/unify_builder/
```

### Commands

| Command | Description |
|---|---|
| `build` | Incremental build |
| `rebuild` | Full rebuild |
| `clean` | Clean build artifacts |

### Options

| Option | Description |
|---|---|
| `--params <path>` | Path to builder.params file (required) |

### builder.params

`builder.params` is a JSON file automatically generated by EIDE from `eide.yml`, containing the complete build configuration:

- `name`: Project name
- `target`: Configuration name (ConfigName)
- `toolchain`: Toolchain type (AC5/AC6/GCC)
- `toolchainLocation`: Toolchain path
- `sourceList`: List of source files
- `incDirs`: Include directories
- `defines`: Preprocessor macro definitions
- `options`: Compilation and linking options
- `env`: Environment variables (including artifact output paths, etc.)
- `dumpPath` / `outDir`: Build output directory

### Build Artifacts

Build artifacts are output to the `build/<ConfigName>/` directory:

| File | Description |
|---|---|
| `<ProjectName>.axf` | Keil-compatible debug file |
| `<ProjectName>.elf` | ELF executable file |
| `<ProjectName>.hex` | Intel HEX flash file |
| `<ProjectName>.bin` | Binary flash file |
| `<ProjectName>.s19` | Motorola S19 format |
| `<ProjectName>.map` | Linker map file |
| `compiler.log` | Compilation log |
| `unify_builder.log` | Builder log |
| `builder.params` | Build parameters |

### Common Compilation Errors

| Error Type | Likely Cause |
|---|---|
| `error: A1023E: missing "{" after #include` | ARM assembly file uses C-style include |
| `error: L6218E: Undefined symbol` | Missing source files or libraries during link phase |
| `Fatal error: L6002U: Could not open file` | Linker script path does not exist |
| `No such file or directory` | Include path or source file path is incorrect |
| `command not found` | Toolchain is not installed or path configuration is incorrect |

### Relationship with UV4

EIDE projects can share the same ARM CC toolchain with Keil MDK projects. The `.axf` and `.hex` files produced by both are fully compatible:

- `toolchainLocation` in EIDE `builder.params` points to ARM CC in the Keil installation directory
- The `env.KEIL_OUTPUT_DIR` environment variable indicates the output directory expected by Keil
- The linker script (scatter file) is shared with the Keil project
